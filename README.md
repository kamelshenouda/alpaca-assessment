# Kamel Nabil × Alpaca · Take-home

An interactive, Notion-style story of my Alpaca product take-home:

- **Part 1:** my biggest achievement, taking IPO subscriptions at Awaed from never launched to live in 6 weeks.
- **Part 2:** the analysis of Alpaca's monthly B2C revenue, step by step, ending in 3 recommendations.

**How to use it:** press → to open the next section, ← to go back, Esc to collapse all, or click any toggle.

Full write-up: [Notion](https://app.notion.com/p/kamelnabil/Kamel-Nabil-Alpaca-Challenge-3ee40603942b81b3bc5ed92af7f76a59)

This is a static site with no build step. Open `index.html`, or serve the folder with GitHub Pages.
